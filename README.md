# Blogify - Full Stack Blog Platform

## 📌 Project Description
Blogify is a modern and responsive full-stack blog platform developed using HTML, CSS, JavaScript, Node.js, Express.js, and MongoDB. Users can create and publish blog posts through a clean and elegant interface.

---

## 🚀 Features
- Modern and responsive UI
- Create and publish blog posts
- Dynamic blog cards
- Login functionality
- Beautiful dark theme design
- Interactive frontend
- Backend integration using Node.js and Express.js
